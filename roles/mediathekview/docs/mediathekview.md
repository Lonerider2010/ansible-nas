# Hello World

Homepage: <https://mediathekview.de/>

The MediathekView program searches the online media libraries of various broadcasters (ARD, ZDF, Arte, 3Sat, SWR, BR, MDR, NDR, WDR, HR, RBB, ORF, SRF) and lists the programs found. The list can be searched for items using various filters. The films can be watched and recorded using a program of your choice. Subscriptions can be created, and new items can be downloaded automatically.

## Usage

Set `mediathekview_enabled: true` in your `inventories/<your_inventory>/nas.yml` file.

The MediathekView web interface can be found at <http://ansible_nas_host_or_ip:5800>.
